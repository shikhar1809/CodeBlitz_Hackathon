# Winger

**WhatsApp location is a dot nobody is watching. Winger is the one watching, and it talks to you.**

Winger is a voice-first personal safety app for women (India first), by **Team AfterBurners**, built for CodeBlitz (ElevenLabs track).

> Status: being built live during the hackathon. This README grows with every push.

## Build

```bash
cd app
flutter pub get
flutter test
flutter run -d chrome --dart-define=WINGER_DEMO=true
```
